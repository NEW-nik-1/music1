# MUZER play — clean ID3 export

При экспорте WAV/MP3 файл создаётся заново, а ID3 формируется с нуля по белому списку стандартных полей редактора.

Исходные и скрытые ID3 frames (`TXXX`, `PRIV`, `GEOB`, `UFID`, `APIC` и другие неизвестные frames) не копируются. AI-метаданные исходного файла поэтому не переносятся в готовый трек.

Название и исполнитель сохраняются оригинальными. Track ID при каждом экспорте создаётся заново.


## UI updates
- Все индикаторы прогресса с процентами собраны под кнопкой «СТУДИЙНЫЙ АВТОМАСТЕРИНГ».
- «СОХРАНИТЬ WAV/MP3» открывает выбор папки на Рабочем столе ПК; файл создаётся внутри выбранной папки.
- Мелкий текст интерфейса немного увеличен для читаемости.

## Quality presets

1. Стандартное качество MP3 — 128 kbps / 44.1 kHz
2. Хорошее качество MP3 — 192 kbps / 44.1 kHz
3. Максимальное качество MP3 — 320 kbps / 48.0 kHz
4. Стандартное качество WAV — PCM 16-bit / 44.1 kHz
5. Высокое качество WAV — PCM 24-bit / 48.0 kHz
6. Студийное качество WAV — PCM 24-bit / 96.0 kHz

Список качества автоматически переключается вместе с форматом WAV/MP3.
