# Studio Mastering Portable Console — исправленная версия

## Что исправлено
- HTML-элементы больше не накладываются на нарисованные кнопки фона: реальные плееры закрывают только зоны транспортных кнопок.
- Дека A — исходный трек (ДО мастеринга), Дека B — результат (ПОСЛЕ).
- Добавлены реальные полосы времени, таймеры и waveform для обоих плееров.
- Центральный экран полностью заменяет нарисованный текст и показывает информацию о треке, метрики ДО/ПОСЛЕ и A/B сравнение.
- Рабочие L/R индикаторы размещены поверх верхних индикаторных полос.
- Исправлены отсутствовавшие поля before/after LUFS, True Peak и RMS, из-за которых загрузка могла завершаться ошибкой.
- Кнопки анализа, Auto-EQ, компрессии, лимитера, спектра, нормализации, WAV/MP3 и настроек собраны в отдельной нижней полосе.

## Запуск
Распакуйте папку целиком и запустите `Studio Mastering.cmd`.

`studio-background.png` должен находиться рядом с `index.html`.

WAV и мастеринг работают локально. MP3-кодировщик в этой сборке загружается через CDN, поэтому для MP3-экспорта требуется интернет.


## Новая панель сохранения
Нижняя панель содержит только сохранение готового мастера:
- Сохранить WAV — PCM 16-bit.
- Сохранить MP3 — с LAME.
- Качество: НИЗКОЕ / СРЕДНЕЕ / ВЫСОКОЕ.
- Профили качества: Низкое — 128 kbps / 44 kHz; Среднее — 128 kbps / 48 kHz; Высокое — 320 kbps / 48 kHz.
- Во время мастеринга отображается процент выполнения от 0 до 100%.
